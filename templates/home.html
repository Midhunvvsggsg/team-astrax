Role-Based Access Control

Server-enforced boundaries across all operations

  • Admin
    System Master: Creates staff accounts, sets discount rules, defines products, plans, and taxes. Controls finance analytics.
  • Staff
    Operations Team: Manages customer subscriptions, confirms invoices, records incoming payments, and tracks overdue accounts.
  • Customer
    Self-Service Portal: Views their own active plans, inspects invoice breakdowns, and completes payments independently.

Core System Directives

Built per hackathon criteria

  • Robust Password Security: > 8 chars, uppercase, lowercase, and special character checks validated client-side and server-side.
  • Case-Insensitive Unique Emails: Consistent identity matching preventing duplicate registrations.
  • Offline Resilience: Console email backend enabled for instant local password resets without external network dependencies.
  • Single Design Tokens: Defined once via theme variables, mobile-responsive layout.
